Read [.agents/niftic-app/GUIDE.md](../../../.agents/niftic-app/GUIDE.md) now,
before touching anything, and follow it.

That file is the whole procedure — setup interview, the per-feature workflows,
and the rules that hold everywhere. It lives outside `.claude/` because Codex,
Cursor and anything else that reads `AGENTS.md` need the same instructions, and
two copies of a rule is one copy that goes stale. This skill exists to make sure
you reach it without being asked.

Its `references/` sit beside it and are pruned to this app's branch. Read the one
a procedure names before starting that procedure.
